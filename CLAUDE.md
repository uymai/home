# CLAUDE.md

## Project Overview

Personal homepage built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4. The home page (`app/page.tsx`) links to the main sections:

- **Discord** (`/discord`) — casual gaming Discord server
- **Steam** (`/steam`) — live Steam profile, recent games, and achievements, fetched server-side by `app/api/steam/route.ts` (needs `STEAM_API_KEY` and `STEAM_USER_ID` env vars)
- **Finaglings** (`/finaglings`) — index of experiments and mini-apps; the project list lives in `app/finaglings/page.tsx`
- **Contact** (`/contact`) and **Wishlist** (`/wishlist`, items in `app/wishlist/items.ts`) — intentionally unlinked and left out of the sitemap
- **Recipes** (`/recipes`) — redirects to https://grimoire.uymai.net (configured in `next.config.ts`)

Mini-apps linked from Finaglings:

- Under `/finaglings/`: `nightlight`, `guitar-lizard`, `toilet-paper-math`, `binary`, `big-o`, `np-complete`, `sorting-algorithms`, `bobs-27`, `dart-game`, `dart-checkout`, `workout-tracker`.
- At the top level: **Steve's Game** (`/steves-game`, number-guessing game with hardcoded `ROB_HARD_NUMBERS`), **Number Grid** (`/number-grid`), **Magic Square** (`/magic-square`), and **Warp Protocol** (`/warp-protocol`, simulation with Next Pick / Next Round step-through).

## Commands

```bash
npm run dev        # Start dev server (Turbopack)
npm run build      # Run tests then build
npm run test       # Run Vitest tests (also runs before build)
npm run test:watch # Watch mode tests
npm run lint       # ESLint (flat config in eslint.config.mjs)
```

## Architecture

- `app/` — Next.js App Router pages and components
- `app/components/` — Shared components (Header, Footer, LinkCard, etc.)
- `app/api/` — Route handlers (currently just `steam`)
- `public/` — Static assets: link-card icons, PWA `manifest.json` and `icons/`
- `skills/` — Claude Code custom skills
- `app/site.ts` — `SITE_URL`, used by `metadataBase`, `sitemap.ts`, and `robots.ts`

Mini-apps keep their logic next to their page, usually as a `*Client.tsx` component plus a plain `engine.ts` / data module.

## Metadata

The root layout sets a title template (`%s — uymai.net`). Every `page.tsx` exports `metadata` with a short `title` and `description`. When adding a public page, add its path to `app/sitemap.ts`. The social preview card is generated by `app/opengraph-image.tsx` (reused by `twitter-image.tsx`).

## Testing

Tests use Vitest. Run `npm test` before committing. The `prebuild` script runs tests automatically.

Test files are colocated with source as `*.test.ts` (e.g., `app/warp-protocol/engine.test.ts`, `app/finaglings/workout-tracker/storage.test.ts`).

## Guitar Lizard (`/finaglings/guitar-lizard`)

Scale data lives in `app/finaglings/guitar-lizard/scales.ts`. To add a new scale, call `generateScalePositions` with a sorted interval array (semitones from root) and append an entry to `SCALES`:

```ts
{ id: 'my-scale', name: 'My Scale', positions: generateScalePositions([0, 2, 4, 7, 9]) }
```

`generateScalePositions` produces one fretboard position per scale degree. It uses `OPEN_STRINGS_FROM_E = [0, 5, 10, 3, 7, 0]` (standard tuning pitches from low E=0), which correctly handles the B-string 4-semitone gap. The `startOffset` of each position equals its scale degree interval, so positions anchor correctly for all 12 keys via `ROOT_FRETS` in the client.
